# IPv8 Routing

## Overview

Routing in MatrixNet is:

- Path-based (pipeline driven)
- Overlay-network compatible
- Latency-aware (future)

---

## Routing Types

1. Direct (low latency)
2. Obfuscated (multi-hop)
3. Broadcast (scene sync)

---

## Pipeline Integration

Routing is not fixed — it flows through:

Firewall → VPN → Obfuscation → Transport

---

## Future Goals

- Adaptive routing
- AI-assisted path optimization
- Load balancing across nodes
